# 分子ビューのクリックとダブルクリックの判定

分子ビューのマウスイベントは `qsys::MouseEventHandler` (`src/qsys/MouseEventHandler.cpp`) が
down / move / up からクリック・ダブルクリック・ドラッグに分ける。ダブルクリックは残基の選択の
トグルなどに使われる。

## 規則

- ボタンを離したとき、押してから 2 px 以上動いていなければクリック (動いていればドラッグ)。
- 次の 3 つがそろえばダブルクリック (`INDEV_*BTN_DBLCLICK`):
  - 前回の単クリックから `DBLCLICK_TIME` (500 ms) 以内
  - 前回と同じボタン
  - 前回の位置から縦横それぞれ `DBLCLICK_DIST` (4 px、座標は CSS px) 以内
- ダブルクリックは前回のクリックを使い切る。続く 3 回目は単クリックになる。
- 前回のクリックとして覚えるのは単クリックだけ。

以前は経過時間だけで判定しており、右クリック (コンテキストメニュー) の直後の左クリックや、
離れた 2 点のクリックがダブルクリックになって、残基の選択が意図せずトグルされた。

OS のダブルクリック間隔は使っていない (tritium から C++ へ渡す経路が無い)。
