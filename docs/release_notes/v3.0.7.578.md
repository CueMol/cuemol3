CueMol 3.0.7 (build 578)

The main changes:

- **MD trajectories from the console, MCP and the AI agent (CueMol3)**: open a
  trajectory, add, list, remove and reorder its blocks with commands. PyMOL's
  `load_traj` works in the PyMOL console. What you do in the GUI is recorded
  in History as the same commands.
- **History search with Ctrl-R (CueMol3)**: the console panel and
  `tritium_cli` search earlier commands as zsh does.
- **Surfaces cast Fast GI occlusion (CueMol3)**: molecular surfaces and density
  map surfaces now cast the baked ambient occlusion and key-light shadow.
- Many fixes to the console, the animation panel and the molecule view, found
  while writing the tutorials.

---

## MD trajectories (CueMol3)

- New console commands, also available to MCP clients and to the AI agent
  (enable the agent's `md` toolset):
  - `load_trajectory` opens a topology with one or more trajectory files.
  - `add_traj_block` adds trajectory files to a molecule or a trajectory. A
    plain molecule becomes a trajectory and keeps its own coordinates as
    frame 0; `replace=true` replaces the existing frames instead.
  - `list_traj_blocks`, `remove_traj_block`, `move_traj_block` list, remove
    and reorder the blocks.
  - Options: `reader` (force a format), `nevery` (read every Nth frame) and
    `loadSel` (read only some atoms; the others are removed from the
    molecule for good).
  - File arguments take several files and patterns (`*.xtc`), and Tab
    completes every file in the directory.
- PyMOL console: `load_traj` (the object is guessed as PyMOL does;
  `state=1`, the default, replaces the frames and `state=0` appends;
  `interval`; `selection`). `load` of a trajectory file adds it to the
  matching molecule. `start`, `stop`, `max`, `average` and a few others are
  not supported and are ignored with a warning.
- The PyMOL and ChimeraX consoles treat a trajectory as a molecule, so
  `color`, `show`, `count_atoms` etc. work on it.
- The Open MD Trajectory dialog, drop, and the Trajectory pane's add /
  remove / reorder are recorded in History and can be saved to Actions.
- `load` of a trajectory file on its own explains that it needs a topology.
  A topology (psf / prmtop) opened without coordinates says so.
- The Trajectory pane's toolbar no longer wraps in a narrow window; buttons
  that do not fit move into a "more" menu, as in the Animation panel.

## Console (CueMol3)

- **Ctrl-R history search** in the console panel and `tritium_cli`, in every
  dialect: type to narrow, Ctrl-R again to go further back, Enter to run, Esc
  or Ctrl-G to cancel. On Windows / Linux, Ctrl+R in the prompt searches
  instead of reloading the scene.
- **Tab writes `, `** after an argument it completes while more arguments
  remain.
- `superpose` reports the fit (RMSD, residues, TM-score, sequence identity,
  rotation).
- `list_anim_props` (`anim_props`) lists an animation element's properties
  in the names `set_anim_prop` takes. `set_anim_prop` rejects a renderer,
  camera or molecule name that does not exist, and `list_anims` marks an
  element whose target is gone.
- A script may end with `save_scene`; it saves after the script's changes are
  committed.
- `add_paint` no longer changes the molecule's selection, and a second
  `add_paint` keeps the first colour.
- `set_view` accepts what its help shows: `null` for a skipped argument and
  `[x, y, z]` lists. `view` / `set_view` report the camera rotation in a form
  that can be pasted back.
- `set_bgcolor` is listed under `help viewing`.
- Load and fetch commands fail, listing the choices, when asked for a preset
  or renderer type the object cannot have, instead of loading it without a
  renderer. A molecule loaded without a renderer still gets the default
  colours.
- Load and fetch commands number new renderers across the scene, as the
  dialogs do. Replaying an older History record in a scene with many
  renderers may give different renderer names.

## Display and GUI (CueMol3)

- Fast GI: molecular surfaces and density map surfaces cast occlusion and
  shadow, also in scenes that have only surfaces.
- Double click in the molecule view needs the same button, close in place and
  time. A left click right after closing a context menu no longer toggles the
  residue selection.
- A fetched crystallographic map (2Fo-Fc / Fo-Fc) is drawn around the view
  centre instead of moving the view to the unit cell. Only cryo-EM maps fit
  the view.
- EMDB download waits for the recommended contour level before drawing.
- New Renderer: "Center view on the new renderer" is off by default.
- Mol Struct: **Properties** (or a double click) shows the selected chain,
  residue or atom in the Inspector, read-only.
- Animation panel: the Inspector no longer jumps back to the animation
  element, so scene properties can be edited while the panel is open. The
  total length follows a duration change.

## Builds

- ffmpeg (used to make movies) is now fetched from the CueMol mirror: 9.1 on
  macOS Apple silicon and Windows, 8.0 on macOS Intel. The Windows ffmpeg was
  from 2014; the installer is larger because of it.
- A development build no longer removes the installed app's local API info
  file.
- Development dependency updates (vite, zod).
