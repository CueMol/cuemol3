CueMol 3.0.2 (build 560)

The main changes:

- **Animation (CueMol3)**: a new **Rock** element swings the view (rock,
  nutate or wobble); animation elements can be copied and pasted; the ChX and
  PyM consoles make camera motions (`turn ... frames`, `roll`, `rock`,
  `wobble`, `movie.roll`, `movie.add_nutate`, ...) as animation elements.
- **Styles view (CueMol3)**: style sets, their named colours and selections
  are edited in a new **Styles** sidebar view.
- **MD trajectories (CueMol3, MD Tools plugin)**: a dropped trajectory file
  can be attached to an open molecule, and topology-only prmtop / PSF files
  can be opened and given coordinates afterwards.
- **PyMOL 2.x sessions (CueMol2 core and CueMol3)**: `.pse` files saved by
  PyMOL 2.x (Python 3) open.

---

## Animation (CueMol3)

- **Rock element**: Add > **Rock** swings the view around the orientation it
  starts from. Its **Pattern** is Rock (back and forth about one axis),
  Nutate (the view circles) or Wobble (a figure 8), with the swing angle,
  number of cycles, phase, aspect and an envelope (grow / shrink). An element
  starts without a jump wherever it is placed. A Rock and a Simple spin at the
  same time turn while swinging.
- **Copy / paste**: in the Animation panel, Edit > Cut / Copy / Paste
  (Cmd+X / C / V) duplicate an element. A pasted element keeps its length,
  follows the selected element (or goes at the end) and gets a unique name.
  Pasting into another scene works.
- **Simple spin**: the rotation angle has no range any more: a negative angle
  spins the other way and 720 spins twice.
- The panel header no longer spills out of its row when the panel is narrow:
  controls that do not fit move into a **...** menu.
- A timeline emptied and begun again starts from the current view (the
  `__current` start camera is saved again), not from a camera saved before a
  molecule was loaded.

## Camera motions from the consoles (CueMol3)

- **ChX console**: `turn y 2 180` (with a frame count) adds the turn to the
  animation and plays it once. `roll`, `rock` and `wobble` (and `turn ...
  rock N` / `wobble N`) run until `stop`, as one cycle played in a loop; `stop`
  puts the loop setting back.
- **PyM console**: `movie.add_roll`, `movie.add_rock`, `movie.add_nutate`,
  `movie.roll`, `movie.rock`, `movie.nutate` and `movie.tdroll` add to the
  animation (play with `mplay`). `rock` starts and stops rocking (`rock 1` /
  `rock 0`).
- Speeds and phases follow ChimeraX and PyMOL roughly, not exactly.
  `movie.screw`, PyMOL's `sweep_*` settings and the `movie.roll(...)` Python
  call form are not supported.

## Styles view (CueMol3)

- A new **Styles** activity view lists the style sets the scene can see, in
  lookup order, with panes to edit a set's named **Colors** and
  **Selections** in place. Style sets are no longer in the scene tree.
- Changing a named colour now redraws the ribbons that use it.
- The bundled style sets are read-only; the `user` set stays editable.

## MD trajectories (CueMol3, MD Tools plugin)

- Dropping a `.xtc` / `.dcd` / `.trr` / `.nc` file asks which molecule to
  attach it to, listing the molecules whose atom count matches. The molecule
  becomes a trajectory with its own coordinates as the first frame.
- prmtop and PSF topologies open without coordinates; coordinates (AMBER
  restart, NAMD `.coor`) or trajectories are attached afterwards. **File >
  Open MD Trajectory** accepts topology files.
- Scenes with a reversed NAMD `.coor` + PSF source (`srctype="namdcoor"`) no
  longer load.

## Explorer, panes and dialogs (CueMol3)

- The Explorer shows the Scene, Camera, Color and View panes; the separate
  View activity button is gone.
- Dialogs start from the options last confirmed, also after a restart (file
  open, New Renderer, merge, superpose, APBS, Export PNG, ...). Dialogs that
  remember numeric parameters have a **Defaults** button.
- **Get PDB** can fetch a ligand by its CCD code (ideal coordinates from
  RCSB), also as `open ccd:ATP` in the ChX console.
- **Nucleic acid renderer**: the Base type has a **None** choice that leaves
  only the backbone tube.
- **Mol Struct pane**: a chain with very many residues (an MD system's water)
  opens at once and adds residues as you scroll.
- **Undo history**: repeated edits of the same value in the GUI are merged
  into one step once the history passes 20 steps (`label ×N` in the History
  pane).
- **ChX console**: AlphaFold palettes (`alphafold`, `pae`, ...); a model
  fetched from AlphaFold DB keeps its pLDDT colouring for every renderer.

## Fixes

- **PyMOL 2.x sessions** (CueMol2 core and CueMol3): `.pse` files from
  Python 3 PyMOL failed with "Unknown opcode 41", or lost most atoms of a
  residue with duplicate atom names. They now load; clashing atom names are
  renamed. Bonds are still generated from distances, not read from the
  session. (Contributed by @AunderbTommy888.)
- Adding a renderer to a molecule no longer resets the colours of its other
  renderers.
- MD trajectories count as molecules: they get their own palette colour and
  appear in the molecule pickers. Superpose, morph, atom deletion and merge
  refuse them.
- Multi-colour gradient edits on a molecule opened from the ChX console
  redraw and undo correctly again. Scripts that set `iter.target = mol` on an
  atom / residue / chain iterator must use `iter.setTarget(mol)`.
- Superposition: the default moving molecule is no longer the same as the
  reference.
- A scene opened from `Untitled 1.qsc` is named `Untitled 1`, so a new scene
  becomes `Untitled 2`; tabs no longer show `.qsc`.
