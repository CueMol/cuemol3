CueMol 3.0.3 (build 565)

The main changes:

- **CueMol2 scenes keep their look (CueMol3)**: a scene saved by CueMol2 is
  drawn as CueMol2 drew it. New scenes get the CueMol3 look, and any scene can
  be switched to **Legacy mode** (CueMol2 look) in Scene Properties.
- **Camera inspector (CueMol3)**: a camera's name, source, stored view and
  visibility flags are shown and edited in the inspector, replacing the Edit
  vis flags dialog.
- **Long tasks show progress (CueMol3)**: saving, opening, surface generation,
  export and trajectory loading show what is running and for how long.
- **Actions follow the tab in front (CueMol3)**: with Settings or no tab in
  front, scene actions are disabled instead of misbehaving.

---

## Scene look: CueMol3 and Legacy mode (CueMol3)

- A qsc made by CueMol2 used to be drawn differently in CueMol3 (ribbons and
  nucleic acids). It now keeps the CueMol2 look; the CueMol3 look is carried
  per scene.
- New scenes get the CueMol3 look. The **New Tab** dialog and **Settings >
  Display > Compatibility** can make **Legacy mode** the default for new
  scenes.
- **Scene Properties > Compatibility > Legacy mode (CueMol2 look)** switches an
  open scene's look in one undoable step. The default colours of new renderers
  follow the look (palette colours, or CueMol2's colours in Legacy mode).
- **Save As** offers "Ver 3.0 or later" as the default format, which refers to
  the CueMol3 look instead of embedding it. Saving as Ver 2.3 embeds it.
- Known limitation: a CueMol3 qsc re-saved by CueMol2 built from this release
  may keep the Ver 3.0 form, which an older CueMol2 cannot read.

## Cameras (CueMol3)

- **Camera inspector**: the Camera pane has a **Property** button and a
  **Properties...** context menu item (double-click still applies the camera).
  The inspector shows the name, the source file (with Reload / Save), the
  stored view and the visibility flags, and follows the pane's selection.
- Visibility flags are edited in the inspector: each change is one undo step,
  and **Capture** records the scene's current show / hide state. The separate
  Edit vis flags dialog is gone.
- The `__current` camera (the current view point, also the default animation
  start) now exists in every scene from creation, is kept up to date, cannot
  be deleted or renamed, and is not part of the undo history. **Save Current
  View** no longer marks the scene modified or clears Redo.

## Animation (CueMol3)

- Dragging a strip in the Animation panel shows its length and start / end
  times next to the dragged edge.
- The dragged edge snaps to a tenth of the ruler tick; hold **Alt (Option)** to
  drag freely. The timeline grows as a strip is dragged past its end.

## Long tasks (CueMol3)

- Saving and opening scenes, loading files, making molecular surfaces,
  exporting and saving objects, and loading MD trajectories show a card with
  the task, the file name and the elapsed seconds (with a progress bar for
  trajectories). The status bar shows the same instead of "Busy", and a task
  that took 5 s or more leaves its duration there.

## Tabs, menus and windows (CueMol3)

- With Settings or no tab in front, menu items, toolbar buttons, shortcuts and
  file drops that need a molecule view are disabled. The Console, Animation,
  Sequence and Trajectory panels ask you to switch to a molecule view tab.
- The command line (`tritium_cli`), MCP, the agent and files opened from the
  OS run in the molecule view tab last in front, instead of creating a new
  scene.
- The welcome screen has a new icon and lists the shortcuts usable with no
  tab open.
- Resizing the main window or the Rendering window keeps the widths of the
  sidebar, the inspector and the Render Settings pane.
- Toolbar: Open File and Save File As have clearer icons; Save As is now
  labelled **Save File As**.

## Rendering (CueMol3)

- The NPR **Detail** tab is laid out like the Render tab, and its numeric
  hatch fields can be dragged and stepped within their ranges.
- The Render Settings pane no longer shows a horizontal scrollbar and a white
  corner.
